# Plan: Local Backend Setup with Centralized API URL

## Problem
Frontend (`leads`) has 14 hardcoded `https://admin.leadsagri.com/api/` URLs across 10 files. The remote server is down, causing `ERR_CONNECTION_TIMED_OUT`. The `leadsAd` backend already has CORS configured (Laravel 12 built-in, allows all origins for `api/*`), so no backend changes needed.

## Approach
Add a `VITE_API_URL` environment variable to the frontend, then replace all 14 hardcoded URLs with it. Configure axios baseURL globally for the 8 axios calls, and use the env var directly for the 6 native `fetch()` calls.

## Changes

### 1. Add `VITE_API_URL` to frontend `.env` and `.env.example`
**Files:** `C:\Users\kdrak\leads\.env`, `C:\Users\kdrak\leads\.env.example`

Add at the bottom:
```
VITE_API_URL=http://localhost:8000
```

For production, this gets set to `https://admin.leadsagri.com` (once the server is back).

### 2. Set axios baseURL in `bootstrap.js`
**File:** `C:\Users\kdrak\leads\resources\js\bootstrap.js`

Add `axios.defaults.baseURL = import.meta.env.VITE_API_URL || ''` so all axios calls automatically use the configured API URL.

### 3. Replace hardcoded URLs in axios-based components (8 files → make paths relative)
Since axios will have `baseURL` set, change absolute URLs to relative paths:

| File | Line | Change |
|------|------|--------|
| `resources/js/components/SugarcaneProductsSection.vue` | 185 | `'https://admin.leadsagri.com/api/products'` → `'/api/products'` |
| `resources/js/components/VegetableProductsSection.vue` | 298 | same |
| `resources/js/components/RiceProductsSection.vue` | 352 | same |
| `resources/js/components/OthercropProductsSection.vue` | 240 | same |
| `resources/js/components/MangoProductsSection.vue` | 296 | same |
| `resources/js/components/NewsSection.vue` | 64 | `'https://admin.leadsagri.com/api/news'` → `'/api/news'` |
| `resources/js/components/FeaturedNews.vue` | 109 | same |
| `resources/js/components/ContactUs.vue` | 211 | `"https://admin.leadsagri.com/api/distributors"` → `'/api/distributors'` |

### 4. Replace hardcoded URLs in fetch-based files (2 files → use env var)
**File:** `C:\Users\kdrak\leads\resources\js\App.vue`

Replace all `https://admin.leadsagri.com` with a local const:
```js
const API_BASE = import.meta.env.VITE_API_URL || '';
```
Then use template literals: `` `${API_BASE}/api/products` `` etc.

5 occurrences in App.vue (lines 1602, 1612, 1624, 1635, 1680).

**File:** `C:\Users\kdrak\leads\resources\js\components\JobCareers.vue`

1 occurrence (line 195): same approach with `import.meta.env.VITE_API_URL`.

### 5. Start the backend server
The `leadsAd` project needs `php artisan serve` running on port 8000. No code changes needed in `leadsAd` — CORS is already configured to allow all origins on `api/*`.
